# NIK MODS

Dark/blood-red, mobile-first GitHub Pages catalog. It automatically reads published GitHub Releases from this same repository.

## Publish the site
GitHub → Settings → Pages → Deploy from branch → **main** → **/(root)**.

## Future workflow
1. Open this repo.
2. Releases → New release.
3. Upload the authorized file as a release asset.
4. Publish the release.
5. Refresh the site — the new card appears automatically.

No HTML/CSS/JS edit is needed for normal uploads.

Only distribute files you are legally authorized to distribute. Do not use the site for pirated/cracked software, malware, or unauthorized access tools.
